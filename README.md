# Arctic-Video
#### An FPGA card designed around video, audio, and PCIe.
Built on a Xilinx Artix-7 75T FPGA chip, with jtag programming, video and audio ports on the card, and DDR3L RAM.

- XC7A75T-2FGG676C
- 256Mb spi flash
- 1GB DDR3L RAM
- 2 6G-SDI ports
- 1 2-lane DisplayPort
- PCIe gen 2 x4 interface
- JTAG programming
- 6 status LEDs

This hardware is untested, use the designs at your own risk!
